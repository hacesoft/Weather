# Počasí: mobilní rozložení

Verze: 1.0.0. Aplikace používá Layout API Shared App Core na Nextcloudu 35.

Přehled a výstrahy používají posuvnou oblast Core. Na telefonu se přehled, mapa, výstrahy, výběr lokality a nastavení otevřou z plovoucí nabídky vpravo u záhlaví. Přepínače Radar / Vítr / Bouřky / ALADIN jsou přímo na mapě, přehrávání u jejího spodního okraje a další nástroje za tlačítkem nastavení mapy. Časová osa a volba srážek či teploty ALADINu se otevřou přes ⋯, legenda přes 🌦️. Nabídka se po výběru položky zavře. Vybrané místo v mapě lze zavřít křížkem. Jedním prstem posunujete mapu, dvěma prsty měníte přiblížení. Vítr mezi body modelové mřížky plynule interpoluje. Radarové obrázky nyní podává server Počasí ze stejného původu jako Nextcloud; podkladové mapové dlaždice dále poskytuje proxy/cache Core. Výpadek radarového poskytovatele zobrazí hlášení u časové osy.

## Kontrola na telefonu

Přibližte přehled mimo mapu a posuňte jej nahoru, dolů i do stran; pak zvlášť vyzkoušejte gesta mapy a nastavení.
